# Flutter Chat App

A real-time messaging application featuring secure authentication and instant data synchronization.

## 🚀 Features

* **Google Sign-In:** One-click authentication using Google credentials.
* **Email Authentication:** Secure login and registration flows via Firebase.
* **Real-time Messaging:** Instant message delivery and updates.
* **State Management:** Clean and scalable architecture powered by Provider.

## 🛠️ Tech Stack

* **Frontend Framework:** Flutter
* **State Management:** Provider
* **Backend Platform:** Firebase
* **Database:** Cloud Firestore
* **Authentication:** Firebase Authentication & Google Sign-In
